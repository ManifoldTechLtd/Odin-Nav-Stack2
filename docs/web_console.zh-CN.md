# ONS2 Web 控制端全流程使用指南

[English](web_console.md) | **中文**

`web_console/` 是 ONS2 内置的一体化**浏览器端导航控制终端**（单进程、单端口 `18090`，同时支持 HTTP 与 HTTPS），替代了传统的命令行交互脚本（`test_nav_control_*.py`）与旧版远程监控页面。通过浏览器即可完成从**启停整套导航栈**到**下发巡检任务、遥控接管、在线录包与现场喊话**的全流程操作：

- **一键启停导航栈（SW01 / ROS 2）**：在网页端直接选择地图、局部规划器（`NeuPAN` 或 `SRU` 端到端策略模型）与导航模式，拉起或停止整套导航栈并实时查看各阶段就绪闸门日志。
- **全局地图与实时位姿**：实时渲染 `/map` 占据栅格地图、机器人位置与朝向（`map → base_link`）以及航点连线。
- **可视化航点编排与任务控制**：地图左键点选添加航点（按住拖动设定目标朝向），编辑停留时间、循环巡检或临时插队任务，支持 JSON 导入/导出，以及暂停、恢复、跳过当前点、取消、返航、重置。
- **底盘运动使能门控（SW01）**：页面一键使能或断开底盘速度桥，与导航栈启动解耦，防止误动。
- **锁存急停与人工遥控接管**：大号急停按钮（软件锁存）+ 带看门狗保护的网页遥控（鼠标按住方向键或键盘 `W/A/S/D/Q/E`，松开即停）。
- **在线 ROS 2 录包**：内置 `轻量 (LIGHT)`、`全量 (TOTAL)`、`导航核心`、`感知`、`调试` 预设，点击预设自动替换勾选当前在线话题，运行在独立 `ons2_bag` 会话中。
- **驻留安全告警、按需相机与语音喊话**：任务途中国际化卡滞检测告警、按需低带宽拉流相机（1/2/5 fps），以及文字转语音（TTS）/ 麦克风对讲 / 音频上传播报。

> **平台支持状态**：ROS 2 Jazzy（ASTRALL SW01）已完成实机全流程验证；ROS 1 Noetic（Unitree Go2、Dobot Lumo）共享同一套地图、任务、急停、遥控、相机与喊话能力（一键启停导航栈与在线录包卡片面向 SW01 ROS 2 编排）。

## 1. 部署与启动 Web 控制端

### 1.1 开机自启服务（推荐，SW01 实机默认方式）

在车载主机上安装 `scripts/systemd/web-console.service` 后，Web 控制端随系统开机自动运行，且独立于导航栈的 `tmux` 会话（停止或重启导航栈不会中断网页连接）：

```bash
REPO=/home/mt/base_inspection   # 替换为你的仓库路径

sudo install -m 644 "$REPO/scripts/systemd/web-console.service" /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now web-console.service

# 检查运行状态
systemctl is-active web-console.service
```

> **注意**：通过网页端启动导航栈后，`ons2_sw01` 会话归属于 `web-console.service` 的控制组。机器狗站立或导航运行期间，请通过页面上的**「停止导航」**管理导航栈，不要直接执行 `systemctl restart web-console.service`。

### 1.2 手动命令行启动

在仓库根目录下先加载对应 ROS 环境再运行：

```bash
# ROS 2（Ubuntu 24.04 / Jazzy）
export ROS_DOMAIN_ID=98
source /opt/ros/jazzy/setup.bash && source ros2_ws/install/setup.bash
python3 -m web_console.run --port 18090

# ROS 1（Ubuntu 20.04 / Noetic）
source /opt/ros/noetic/setup.bash && source ros_ws/devel/setup.bash
ROS_VERSION=1 /usr/bin/python3 -m web_console.run --port 18090
```

常用启动参数：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--host` | `0.0.0.0` | 监听网卡地址 |
| `--port` | `18090` | HTTP 与 HTTPS 共用的单端口 |
| `--no-tls` | 关闭 | 仅开启明文 HTTP（禁用自签名 HTTPS） |
| `--map-topic` | `/map` | 占据栅格地图话题 |
| `--map-frame` / `--base-frame` | `map` / `base_link` | 机器人位姿 TF 查询坐标系 |
| `--odom-topic` | `/odin1/odometry` | 安全驻留监测使用的里程计话题 |
| `--cmd-vel-topic` | `/cmd_vel` | 遥控速度发布话题 |
| `--image-topic` | `/odin1/image/compressed` | 按需相机订阅话题 |
| `--stall-window-sec` / `--stall-radius-m` | `30` / `0.20` | 原地卡滞告警时间窗口（秒）与位移半径（米） |

### 1.3 浏览器访问与网络说明

- **局域网访问**：在同一有线网或 Wi-Fi 下打开浏览器访问 `http://<机器人IP>:18090`（若需使用浏览器麦克风对讲，请访问 `https://<机器人IP>:18090` 并在首次连接时信任自签名证书）。
- **4G / 跨网远程访问**：Web 控制端无内置云中继或账号密码，跨公网访问需自行配置 VPN 或内网穿透（如 frp），将单个端口映射至机器人 `127.0.0.1:18090`，并务必配置访问认证以保证安全。

## 2. 控制整个导航全流程操作步骤

下面以 **ASTRALL SW01（ROS 2）** 实机巡检为例，介绍在网页端从零启动并完成导航任务的完整流程：

### 第一步：启动导航栈（「导航（SW01）」卡片）

1. **选择地图**：下拉框会自动扫描 `ros2_ws/src/map_planner/maps/` 下的 `.yaml/.pgm` 地图，并标注在 `customer_file/` 下是否存在同名 `.bin` 重定位地图（显示 `（有重定位文件）`）。
2. **选择局部规划器**：
   - `NeuPAN（默认）`：基于全局 A\* 路径 + 解析式 DUNE 局部 MPC 避障，无需训练模型。
   - `SRU 策略`：切换为端到端深度视觉导航，此时会出现「策略」下拉框（自动检测 `sru/models/` 下的 `main` / `conservative` / `roll_v2` ONNX 模型是否就绪）。
3. **选择导航模式**（NeuPAN 下生效）：
   - `replan_periodic（默认）`：周期全局重规划 + 路径受阻热更新，推荐日常巡检使用。
   - `escape`：启用后退转向/横移局部脱困。
   - `neupan_only`：仅初始全局规划一次，全程由局部规划器跟踪。
4. 点击 **「启动导航」** 并确认：后台会自动调用 `scripts/ons2_sw01.sh` 依次拉起 Odin1 驱动、地图服务、规控栈与任务管理器。下方日志框实时滚动输出启动进度，`[OK]` 就绪闸门呈绿色高亮，报错呈红色高亮。
5. 顶部状态栏徽标由 `未运行` 变为绿色的 `运行中`，且定位徽标显示正常位姿后，左侧画布即可看到全局地图与机器人实时位置箭头。

### 第二步：使能底盘运动（「底盘使能」卡片）

出于安全设计，**启动导航栈不会自动让机器狗站立或行走**：
1. 使用物理遥控器控制机器狗起立并切入行走（`MOVE`）模式，随后释放遥控器控制权（交还 SDK 控制权）。
2. 确认机身周围无障碍与人员贴近后，在网页右侧 **「底盘使能」** 卡片点击 **「使能底盘」**（调用 `/sw01_cmd_vel_bridge/enable`）。
3. 若运行途中遥控器重新介入、SDK 断链或底盘报错，底盘桥会自动解除使能，恢复后需再次点击「使能底盘」。

### 第三步：点选编排航点并执行任务（「航点队列」与「任务」卡片）

1. **地图交互采点**：
   - 确保画布右上角 **「点选航点」** 处于高亮开启状态（右键按住拖动可平移地图，滚轮缩放，点击「居中机器人」或「适应地图」快速复位视角）。
   - 在地图可通行空白处**左键点击**即可追加航点；**左键按住并向目标朝向拖动**可直接设定该航点的到达朝向角 `yaw°`。
2. **编辑航点属性**：
   - 在右侧「航点队列」表格中可逐行修改航点 `名称`、`x`、`y`、`yaw°`、`停留s`（到点驻留秒数），或删除单个航点。
   - 可勾选 **「循环」**（首尾循环巡逻）或 **「临时插入」**（暂停当前主线任务，优先跑完临时航点后可恢复主线）。
   - 支持 **「导出 JSON」** 保存固定巡检路线，后续直接 **「导入 JSON」** 一键加载。
3. **下发与过程控制**：
   - 点击 **「执行任务」**，任务立即发送至 `/waypoint_manager/start_mission`。
   - 在 **「任务」** 卡片可实时查看当前状态（`NAVIGATING`、`ALIGNING`、`DWELLING`、`PATH_SAFETY_WAIT` 等）、完成进度、当前航点序号与剩余距离，并随时执行 **暂停 / 恢复 / 跳过当前点 / 取消 / 回起点 / 重置**。

### 第四步：急停与人工遥控接管（「急停与遥控」卡片）

- **紧急停车**：点击红色大按钮 **「急停」** 会立即向 `/emergency_stop` 与 `/neupan/stop` 发送锁存停车指令并中断当前运动；排除险情后点击 **「解除急停」** 才允许重新运动。
- **人工遥控接管**：
  1. 点击 **「开启人工接管」**（自动暂停自动导航指令输出，切换为手动遥控通道）。
  2. 设置线速度（`m/s`）与角速度（`rad/s`），使用页面九宫格方向键或键盘 **`W`（前）/ `S`（后）/ `A`（左横移）/ `D`（右横移）/ `Q`（左转）/ `E`（右转）** 控制移动。
  3. 遥控内置看门狗：一旦松开按键/鼠标或网页断开连接，速度指令立即归零停车。完成后再次点击按钮关闭人工接管即可。

### 第五步：在线录包排障（「录包」卡片）

录包功能运行在独立的 `ons2_bag` `tmux` 会话中，保存到 `~/sw01_bag_recordings/`（可通过环境变量 `ONS2_BAG_ROOT` 修改），页面实时显示磁盘剩余空间、已录时长与当前包体积：

1. **一键切换录包预设**（点击任一预设会自动清空并替换旧勾选项，同时显示 `已选 X / Y` 数量）：
   - **`轻量 (LIGHT)`**（推荐日常排障）：涵盖 TF、里程计、`/cmd_vel`、底盘桥追踪、激光 `/scan` 与 `/scan_360`、全局/局部规划路径、`replan_gate_shadow`、`control_trace`/`escape_trace`、任务状态与日志，体积小、不产生磁盘高负载阻塞。
   - **`全量 (TOTAL)`**：在轻量基础上增加 `/odin1/image/compressed`、`/odin1/cloud_slam`、`/odin1/cloud_raw`、`/map`、`/sliding_map` 等完整感知与建图数据（带黄色 `大` 标签的话题磁盘增长较快）。
   - 另提供 **`导航核心`**、**`感知`**、**`调试`** 快捷分组与 **「清空已选」** 按钮。
2. 也可用上方搜索框筛选话题名手动勾选/取消，或在「手动追加话题」输入框补充尚未发布的话题，填写可选包名前缀后点击 **「开始录包」**。
3. 复现完成后点击 **「结束录包」**，后台会向 `ros2 bag record` 发送 `Ctrl-C` 安全落盘并写出 `metadata.yaml` 与 `*_meta.json`。

### 第六步：辅助监控功能

- **安全监测**：当机器人在任务执行期间长时间位移小于设定半径（默认 `30s` 内不足 `0.20m`）时触发红色闪烁告警与可选提示音；支持开启「强制监测」（非任务态也监测）、「静音 60s」及在线修改窗口与半径。
- **相机（按需取流）**：仅在点击「开启相机」时才向 ROS 订阅 `/odin1/image/compressed` 并按所选帧率（1 / 2 / 5 fps）推流，关闭后零带宽占用。
- **喊话（机器人扬声器）**：支持输入任意文本 TTS 播报、点击预设快捷用语、浏览器麦克风实时录音喊话（需 HTTPS 或 `localhost`）以及上传本地音频文件在机身扬声器播放。

## 3. 常见问题速查

| 现象 | 原因与处理办法 |
|---|---|
| 顶部显示 `无定位` 或地图空白 | 尚未启动导航栈，或 Odin 重定位尚未收敛（检查所选地图是否有重定位 `.bin` 文件及 `map → odom → base_link` TF） |
| 点击「启动导航」提示会话已存在 | 先点击「停止导航」（或在终端执行 `bash scripts/ons2_sw01_stop.sh`）清理残留 `ons2_sw01` 会话后再启动 |
| 下发航点后机器人原地不动 | 检查「底盘使能」卡片是否已点击「使能底盘」，以及遥控器是否已切入 `MOVE` 模式并释放控制权；检查顶部是否处于 `急停中` |
| 切换为 SRU 策略时某策略不可选 | 对应 `.onnx` 模型尚未放入 `sru/models/` 目录（见 `sru/README.md`） |
| 录包时机器人控制出现明显滞后 | 勾选了未压缩原图（`/odin1/image`）或多路稠密点云导致磁盘写入打满；日常规控排障请优先使用 **`轻量 (LIGHT)`** 预设 |
| 无法使用麦克风录音按钮 | 浏览器安全策略限制非 `localhost` 必须使用 HTTPS，请改用 `https://<机器人IP>:18090` 访问 |
